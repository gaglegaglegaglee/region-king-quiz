# VS · 지역 비교 퀴즈

실제 공공데이터로 대한민국 지역 상식을 겨루는 웹 퀴즈입니다.

- 게임: https://gaglegaglegaglee.github.io/region-king-quiz/
- 게임 서버: https://region-king-api.dotlee.workers.dev
- 주제: 모든 분야 도전 / 사람 / 자연 / 지리 / 산업
- 문제당 15초, 목숨 1개. 정답·연승·공용 순위는 서버에서 확인합니다.
- 비교 지표 39가지, 소속 시·도, 모양→이름·이름→모양, 전화 지역번호 양방향, 교량·터널의 기록상 소재지, 철도 부재 확인 사례 문제를 제공합니다.
- 전체·이번 주(한국시간 월요일부터) 순위, 별명 등록, 이 브라우저의 주제별 최고 기록을 제공합니다.

화면은 GitHub Pages의 정적 HTML·CSS·JS입니다. 정답 판정과 순위 저장은 Cloudflare Workers + D1이 맡습니다. 웹에는 데이터 이용 열쇠나 운영자 비밀번호가 없습니다.

## 데이터

KOSIS 통계는 통계별 기준일·출처와 함께 보존합니다. 산업 분야에는 자동차 등록 대수와 인구 1,000명당 자동차 수를 사용합니다. 등록지와 렌터카 등의 영향으로 극단값이 나타난 지역은 기존 검증 기준에 따라 제외합니다. 행정구역 모양은 VWorld 경계의 KnellBalm 가공본(2023)을 현재 지역 코드와 연결했습니다. 경계가 확인되지 않은 인천 신설 4개 구는 모양 문제에서 제외합니다. 세종·제주의 시군구는 동일 시도 안 4개 보기를 만들 수 없어 모양 문제에서 제외하며 소속·통계 문제는 사용할 수 있습니다.

월간 갱신은 GitHub Actions가 별도 후보를 수집·검증한 뒤 D1의 단일 활성화 문장으로 10개 통계를 함께 교체합니다. 실패한 수집·검증·활성화는 기존 게임 자료를 보존합니다.

기상청 1991~2020 기후평년값으로 연평균 기온·연강수량을 비교합니다. 평균 고도는 공개 표고 격자의 근삿값이고, 동서남북은 경계 안 대표점의 위경도를 비교합니다. 각 문제에 비교 기준을 표시합니다. 자세한 자료·누락 지역·재현 방법은 [자연·위치 데이터](data/nature/README.md)를 참고하세요. 이 자료는 서버에 함께 배포하며 게임 중 외부 API를 호출하지 않습니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| web | GitHub Pages 배포 화면 |
| server | Worker, D1 스키마와 정답·순위·관리자 기능 |
| collector | KOSIS 수집·검증·원자적 갱신 |
| data | 공개 통계와 지역·경계 스냅샷 |

개발 계획은 PRD.md·SPRINTS.md, 실제 이용과 운영은 [운영안내.md](운영안내.md)를 참고하세요.

2026-10-17 주제 정리: 모든 분야 도전 / 인구·나이 / 지도·자연의 3가지. population 주제는 기존 인구4종과 나이3종을 함께 출제합니다. age는 새 판에서 제외하되 기존 기록·진행 판은 보존합니다.

최종 분야 구분: 사람(인구·나이·세대 7지표), 자연(기온·강수량·고도 3지표), 지리(면적·동서남북 5지표 및 지도3종), 산업(자동차2지표). 전체 도전 포함 선택 버튼5개.

확장 비교: 소상공인 등록 점포수·인구당 점포수, 자전거도로·도로·해안선 길이, 쌀 생산량, 전력판매량과 양방향 전화 지역번호 퀴즈를 제공합니다. [자료 기준](data/extra/README.md)을 참고하세요. 철도역과 추가 아이디어 지표는 별도 수집·검증 진행 중입니다.

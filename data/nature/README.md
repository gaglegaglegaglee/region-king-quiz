# 자연·위치 비교 자료

현재 공개 지역 목록 246곳(시도 16, 시군구 230)에 대응한 고정 스냅샷입니다. 서로 같은 행정 단위끼리 비교하며, 답변 뒤 기준일·출처·수치를 공개합니다. 원자료의 시점이 서로 다르므로 현재 관측치로 해석하지 않습니다.

| 지표 | 수록 지역 | 비교 기준 |
|---|---:|---|
| 연평균 기온·연강수량 | 시군구 204 | 기상청 1991~2020 평년값, 해당 지역의 대표 관측지점 |
| 평균 고도 | 241 | 2023 경계 안 약 300m 격자 표고의 면적가중 평균, 근삿값 |
| 동·서·남·북 | 242 | 2023 경계 내부 대표점의 경도·위도 |

## 기후

[기상청 기후평년값](https://data.kma.go.kr/climate/average30Years/selectAverage30YearsList.do?pgmNo=113)의 연간 CSV 원본을 `kma-normals-1991-2020.csv`(CP949)로 보존했습니다. 관측소 좌표는 [공식 평년값 보고서](https://data.kma.go.kr/resources/normals/pdf_data/korea_pdf_0106_v2.pdf)의 관측지점 표에서 읽고 `station-mapping.json`에 보존했습니다. 출처표시 조건에 따라 기상청을 표시합니다.

같은 시도에서 관측소명과 시군구명을 먼저 대응하고, 불명확한 경우 공식 좌표가 하나의 시군구 경계 안에 들어가는지 확인합니다. 한 지역에 여러 지점이 있으면 지역명 일치 → ASOS → 지점번호 순으로 한 곳을 선택합니다. 인접 지역의 값을 복사하거나 시도 평균으로 대체하지 않습니다. 지역 전체의 면적 평균이 아니므로 문제에 대표 관측지점 기준임을 표시하고, 정답 설명에 관측소명도 표시합니다. 차이가 기온 1℃·강수량 100mm보다 작은 쌍은 출제하지 않습니다.

## 표고

[USGS/Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)의 공개 HGT(Skadi) 격자를 사용합니다. 높이는 미터 단위의 해발 표고입니다. [형식](https://github.com/tilezen/joerd/blob/master/docs/formats.md)과 [출처표시 안내](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)를 참고하세요.

각 지역 경계 안 고정 격자를 약 300m 간격으로 표본 추출하고 위도 코사인으로 면적을 보정합니다. 유효 표본 10개 이상, 유효 비율 99.5% 이상인 지역만 사용합니다. 현재의 정확한 공식 평균표고 통계가 아닙니다. 문제에는 근삿값임을 밝히고 10m 단위로 반올림하여 표시하며 50m 이상 차이 나는 쌍만 출제합니다. 인천 신설 4개 구는 경계가 없어 제외하고, 울릉군은 표본 검증 조건 미충족으로 제외했습니다. 제외 사유는 JSON에도 보존합니다.

Attribution: SRTM, GMTED2010 data courtesy of the U.S. Geological Survey; Mapzen.

## 위치

기존 VWorld/KnellBalm 2023 경계 자료를 현재 지역 코드에 대응하고 Shapely `representative_point()`로 경계 안의 대표점을 구했습니다. 청사 위치·지리적 중심·최동서남북 극점과 다릅니다. 문제는 명시적으로 ‘대표점이 더 동쪽/서쪽/남쪽/북쪽’인지 묻습니다. 위도·경도 차이 0.3도 이상인 쌍만 사용합니다. 인천 신설 4개 구는 제외합니다. 경계 자료의 출처·이용조건은 기존 `data/geo/` 문서를 함께 확인하세요.

## 재현·배포

Python의 numpy, shapely, PyMuPDF가 필요합니다. 저장소 루트에서 실행합니다.

```sh
python3 collector/tools/build_nature.py
```

공개 원본은 `.cache/nature/`에 캐시하고 `nature.json`을 원자적으로 생성합니다. 큰 표고 타일·보고서·캐시는 Git에 포함하지 않습니다. 서버 테스트는 CSV와 기후 값의 일치, 표고 표본 검증, 7가지 비교의 방향·정답·출제 간격을 확인합니다.

기존 월간 KOSIS 10종 갱신과 별도 자료입니다. 기후·표고·위치는 필요할 때 재생성·검증하고 Worker를 다시 배포합니다. 게임 중 이용자별 외부 API 요청이나 인증키가 필요하지 않습니다. 기존 자동차 자료는 과거 기록 호환용으로 유지하며 현재 문제·주제·순위 탭에서는 제외합니다.

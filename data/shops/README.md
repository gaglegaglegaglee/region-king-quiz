# 소상공인 상가정보 집계

출처: [소상공인시장진흥공단 상가(상권)정보](https://www.data.go.kr/data/15012005/openapi.do), 이용허락범위 제한 없음. 기준월 2026-06. 원자료에 등록된 점포를 센 값이며 전체 사업자 수·공식 소상공인 수와 다릅니다.

| 소분류 | 범위 | 전국 원자료 건수 |
|---|---|---:|
| G20405 | 편의점 | 54,446 |
| I21201 | 카페(커피숍 비교에 사용) | 122,622 |
| I21001 | 빵/도넛(도넛 포함) | 31,168 |
| R10407 | 노래방(유흥주점과 구분) | 26,572 |

수집기는 `storeListInUpjong`에서 소분류별 전국 모든 페이지를 받은 뒤 전체 건수와 고유 상가업소번호 수를 검증합니다. 시군구별 집계 후 2026 지역 코드에 대응하고 일반시의 행정구는 시 전체로 합칩니다. 광주+전남, 강원·전북 코드 변경도 대응합니다. 인천 신설 4개 구는 공개 시군구 비교에서 제외하고, 인천 시도 값은 원자료 전체를 포함합니다. 자료에서 점포가 발견되지 않는다는 사실을 실제 시설의 완전한 부재로 단정하지 않습니다.

재생성: `DATA_GO_KR_SERVICE_KEY` 환경변수 또는 `SBIZ_ENV_FILE`이 지정한 비공개 파일로 인증을 제공한 후 `python3 collector/tools/build_shops.py`를 실행합니다. 원자료의 상호·주소는 재배포하지 않고 집계값만 공개합니다. 페이지 캐시는 `.cache/sbiz/`에 보관하며 Git 제외입니다. 게임 중에는 이 API를 호출하지 않습니다.

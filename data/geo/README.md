# 지도 경계 출처와 현재 행정구역 연결

- 원본 제공처: 국가공간정보포털(VWorld) 행정구역 경계 shapefile, **2023-07-29 배포본**.
- GeoJSON 가공 제공처: [KnellBalm/kr-admin-geojson](https://github.com/KnellBalm/kr-admin-geojson). 저장소 설명에 좌표변환(EPSG:5179 → WGS84), 0.0005도 단순화 및 출처 표시 조건 자유 이용을 명시. 이 프로젝트는 기존에 내려받은 동일 `sig.geojson`을 `source-sig.geojson`에 보존한다. 자료를 2026년 최신 경계라고 표시하지 않는다.
- 원본 및 가공본 출처를 웹 화면과 문제 해설에 함께 표시한다. 제삼자 가공 자료에 명시된 이용 안내를 따르며 별도의 독점 권리는 주장하지 않는다.
- 현재 행정구역 목록: `../regions.json`, 행정안전부 행정표준코드, 기준일 2026-09-30. 지도 경계의 기준일과 행정구역 명칭 기준일은 다르다.

`collector/tools/build_geo.py`는 원본을 현재 지역 코드에 연결하고, 일반 시의 구 경계를 합쳐 시 단위로 만들고, 광주·전남을 병합한 뒤 SVG 화면 좌표로 투영·단순화한다. 전남 일부 군은 통합 후 번호가 달라졌으므로 단순한 앞 두 자리 치환을 하지 않고 같은 시·도의 정확한 시군명으로 연결한다. `boundaries.json`에는 원본 SHA-256과 제외 목록이 있다.

**지원 범위:** 시·도 16곳과 시·군·구 226곳, 총 242개 경계. 2026년에 새로 나뉜 인천 제물포구·영종구·서해구·검단구 4곳은 옛 경계를 추정해 그리지 않고 모양 문제에서 제외한다. 인천 시도 윤곽은 기존 구 경계의 합집합으로 표현할 수 있다. 세종(시군구 1곳), 제주(2곳)는 같은 시도 안에서 다른 3개 보기를 만들 수 없어 시군구 모양 출제에서 제외하며, 시도 모양과 소속 시도 문제는 지원한다. 소속 시도 문제는 현재 시군구 230곳 모두 출제한다.

## 다시 만들기

Shapely 2.x가 있는 Python 환경에서 프로젝트 루트 기준:

```sh
python3 collector/tools/build_geo.py
```

선택적으로 `--download`를 붙이면 명시된 공개 원본 URL을 다시 받는다. 다운로드는 FeatureCollection 형식과 최소 건수를 확인한 뒤 원본을 교체한다. 전체 변환과 지역 매칭 검증이 성공한 경우에만 `boundaries.json`을 쓴다. 새 인천 경계를 지원하려면 **그 구의 공식 새 경계 자료**를 확보하고 제외 목록과 검증을 함께 변경해야 한다.

`boundaries.json`은 서버가 문제에 필요한 경로만 골라 전달한다. 지도 자체는 공개 사실이지만, 정답 코드·정답 보기 번호·지역별 수치·정답 매핑은 제출 전 응답에 포함하지 않는다. 이름→모양 문제의 보기 코드는 `a`–`d`이며 실제 지역 코드가 아니다.

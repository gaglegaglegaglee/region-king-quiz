# 자료 수집 프로그램 (collector/)

공공데이터를 받아 정리해서 게임 서버 저장소(D1)에 넣는 프로그램입니다. Node.js만 있으면 되고 따로 설치할 것은 없습니다.

## 1. 통계청 열쇠 넣기
인구를 받으려면 통계청 KOSIS 열쇠가 필요합니다.
- 프로젝트 맨 위 폴더(`region-king-quiz/`)의 `.env` 파일에 한 줄을 적습니다. 열쇠 끝의 `=` 기호까지 그대로 넣습니다.
  ```
  KOSIS_API_KEY=여기에열쇠
  ```
- 이 파일은 저장소에 올라가지 않게 막혀 있습니다. 열쇠를 채팅, 문서, 코드에 붙여 넣지 마세요.
- 열쇠가 없거나 틀리면 프로그램이 한국어로 "열쇠가 없어요 / 올바르지 않아요"라고 알려 줍니다.

## 2. 실행 순서 (내 컴퓨터, 로컬 저장소)
```
cd server && npm install && npm run migrate:local      # 저장소 표 만들기
cd ../collector && npm run load-local                  # 지역 목록(시·도, 시·군·구) 넣기
npm run load-population                                # 통계청에서 최신 인구를 받아 넣기
```
확인: `cd ../server && npm run dev` 로 켠 뒤 `http://127.0.0.1:8787/api/health` 를 열면 지역 수와 인구 기준월이 보입니다.

## 3. 시험
```
npm test
```
가짜 통계청 응답으로 지역 맞추기, 이상 감지, 오류 안내를 확인합니다(실제 통계청에는 접속하지 않습니다).

## 4. 만들어지는 파일 (`data/`)
- `data/raw/` 받아 둔 원본(법정동코드)과 출처 설명(`SOURCE.json`)
- `data/regions.json`, `data/regions.sql` 지역 목록(출처·기준일 포함)
- `data/stats/population.json`, `population.sql` 인구 값(단위 명, 기준월, 출처, 받은 시각 포함)
- `data/kosis-region-map.json` 통계청 지역 코드와 우리 지역 코드의 대응표

## 5. 받은 자료가 이상하면
아무것도 저장하지 않고 한국어로 이유를 알려 줍니다. 예시:
- 값을 찾은 지역이 전체의 95%에 못 미침
- 통계청에는 있는데 우리 지역 목록에 없는 지역이 있음(지역 목록 기준일이 자료와 안 맞음)
- 값이 비어 있는 지역이 있음
- 전국 값이 없거나, 시·도 합 또는 시·군·구 합이 전국과 1% 넘게 다름
- 열쇠 문제, 호출 한도 초과, 인터넷 연결 실패

이때 서버 저장소에는 이전 자료가 그대로 남습니다.

## 6. 지역 목록 기준일
지역 목록은 "기준일"에 있던 행정구역으로 만듭니다. 기본값은 2026-09-30(2026-07-01 개편 이후: 시·도 16곳, 시·군·구 230곳)입니다. 통계청 최신 달이 이 구성이어야 인구가 모두 맞습니다.
개편 전 구성(시·도 17곳, 시·군·구 229곳)이 필요하면:
```
node src/build-regions.mjs 2026-06-30
npm run sql
```
(지역 목록을 바꾸면 인구가 그 구성과 맞는지 `npm run load-population`으로 다시 확인합니다.)

## 7. 원본을 새로 받기 (드물게)
`npm run download-raw` (약 5~6분). 행정안전부 행정표준코드관리시스템(code.go.kr)에서 받습니다. 공개 배포 전에 이용 조건을 사이트에서 한 번 더 확인하세요(`data/raw/SOURCE.json` 참고).
